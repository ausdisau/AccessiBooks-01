## AccessiBooks Flipbook Prompt Pack

Below is a **prompt pack** you can paste into Replit Agent piece by piece, or hand over as one structured build sequence. It abstracts the flipbook reader into clear workstreams so the agent can build it without getting lost in the reeds 🌿📚

---

# 1. Master Prompt

```text
Build an accessibility-first eBook flipbook reader for AccessiBooks using React + TypeScript.

The component should feel like a modern interactive reading experience designed for people with disabilities, especially readers with dyslexia, low vision, physical disability, cognitive fatigue, sensory sensitivity, and screen-reader users.

Core goals:
- Create a page-based flipbook reading interface
- Make all reading controls keyboard accessible and screen-reader friendly
- Include dyslexia-friendly typography and reading customisation
- Add built-in browser text-to-speech
- Support written annotations and voice annotations
- Persist reading preferences and notes
- Design the interface to be calm, uncluttered, and highly legible
- Make the reader modular so it can later connect to EPUB, audiobook transcript, and backend APIs

The UI should include:
- Main flipbook page display
- Previous/next page controls
- Search inside the book
- Accessibility settings panel
- Annotation sidebar
- Keyboard shortcuts
- ARIA live status messages
- Reduced motion support

Accessibility requirements:
- WCAG-minded structure and semantics
- Visible focus states
- Full keyboard navigation
- Proper aria-label, aria-live, aria-expanded, aria-pressed, and landmark usage
- High contrast option
- Dyslexia-friendly font options
- Adjustable font size, line height, letter spacing, and word spacing
- Reduced motion mode
- Calm visual hierarchy with large touch targets

Technical requirements:
- Use React with TypeScript
- Use modular components
- Use local state first, but structure for future backend sync
- Use browser SpeechSynthesis API for TTS
- Create a placeholder architecture for MediaRecorder voice notes
- Use localStorage for persistence
- Keep the code clean, strongly typed, and production-minded

Build the solution in small reusable components:
- FlipbookReader
- ReaderToolbar
- ReaderSettingsPanel
- PageNavigator
- ReadingPage
- AnnotationPanel
- KeyboardShortcutHelp
- LiveStatusRegion

Use a polished, modern UI with rounded corners, spacious padding, and a distraction-light reading environment.
```

# 2. Prompt: Core Reader Shell

```text
Create the core shell for an AccessiBooks flipbook reader in React + TypeScript.

Requirements:
- Render a main reader layout with a reading pane and a right sidebar
- Add previous and next page navigation
- Show current page number and total page count
- Add a search bar for finding text in the book
- Add a settings button that opens and closes a settings panel
- Include a list of page thumbnails or page jump buttons
- Use demo page data for now
- Use semantic HTML and accessible labels throughout

The code should be modular and easy to extend later with real book data from an API.
```

# 3. Prompt: Flipbook Animation Layer

```text
Add an interactive page-flip animation layer to the AccessiBooks reader.

Requirements:
- Use smooth page transitions between pages
- Respect prefers-reduced-motion
- If reduced motion is enabled, switch to minimal fade transitions
- Do not let animation interfere with readability or focus order
- Maintain accessibility and keyboard usability during all transitions
- Keep the animation elegant and calm rather than flashy

The reader should still work perfectly without animation.
```

# 7. Prompt: Browser Text-to-Speech

```text
Add built-in browser text-to-speech to the AccessiBooks flipbook reader using the SpeechSynthesis API.

Requirements:
- Add a Read Aloud button
```
