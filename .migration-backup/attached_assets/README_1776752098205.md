# AusDis Access Portal

Centralized authentication and permission-based service access portal for Australian Disability Ltd services.

## Services

- **MapAble**: Accessible mapping and navigation
- **AccessiBooks**: Digital library of accessible books
- **Disapedia**: Accessible knowledge base and wiki

## Features

- ✅ Auth0 authentication with Google login
- ✅ Permission-based service access
- ✅ WCAG 2.2 AA accessibility compliance
- ✅ Server-side authentication gating
- ✅ Secure session management
- ✅ Keyboard navigation support
- ✅ Screen reader friendly

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Authentication**: Auth0 Next.js SDK
- **Styling**: Tailwind CSS
- **Runtime**: Node.js 20+

## Quick Start

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Configure environment variables**
   ```bash
   cp .env.local.example .env.local
   # Edit .env.local with your Auth0 credentials
   ```

3. **Set up Auth0**
   See [docs/AUTH0_CONFIG.md](./docs/AUTH0_CONFIG.md) for detailed instructions.

4. **Run development server**
   ```bash
   npm run dev
   ```

5. **Open browser**
   Navigate to `http://localhost:3000`

## Permissions

The portal uses permission-based access control:

- `service:mapable` - Access to MapAble
- `service:accessibooks` - Access to AccessiBooks
- `service:disapedia` - Access to Disapedia

Permissions are managed in Auth0 and assigned to users via roles.

## Accessibility

This portal is built with accessibility as a priority:

- WCAG 2.2 AA compliant
- Keyboard navigation support
- Screen reader friendly
- High contrast focus indicators
- Semantic HTML
- Proper ARIA labels

## Security

- Server-side session validation
- No client-side token exposure
- Secure cookie settings
- Protected redirects (no open redirects)
- Input sanitization
